# Conocimiento de Andromeda AI

[PENDIENTE: guías, casos, lecciones y material de referencia propios de Andromeda AI.]

Usa esta carpeta para conocimiento que no es un framework: explicaciones, casos de estudio, preguntas frecuentes, glosarios o material de apoyo para la audiencia latinoamericana.

Sugerencias de organización (crea las subcarpetas solo cuando las necesites, según `EXPANSIONS.md`):

- `guias/`: tutoriales paso a paso.
- `casos/`: ejemplos reales y sus resultados.
- `glosario.md`: términos de IA explicados en español.

Cada archivo debe tener un título `# ...`, y conviene que tenga `description` y `updated` en el frontmatter para que el Cerebro 3D los muestre bien.
