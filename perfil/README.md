# Perfil local de NOVA

Los archivos `identidad.md`, `vida_personal.md` y `datos_privados.md` son locales y están excluidos de Git. Si quieres crear un perfil en una instalación nueva, copia los ejemplos, completa solo lo que quieras compartir con NOVA y conserva los nombres esperados por `app.py`.

El perfil es contexto configurado, no memoria de conversaciones. Revisa la vigencia de equipos, proyectos y posesiones antes de tratarlos como actuales.
