# Perfil local de NOVA

Los archivos `identidad.md`, `vida_personal.md` y `datos_privados.md` son locales y están excluidos de Git. En NOVA, `/mantenimiento` abre un formulario para crear o rehacer el perfil y guarda una copia local oculta antes de reemplazarlo. En una instalación nueva, el formulario aparece al iniciar si todavía no existe un perfil.

La sección privada es opcional. El perfil es contexto configurado, no memoria de conversaciones; los recuerdos y planes de SQLite se conservan aparte. NOVA registra la fecha en que completaste el formulario para poder distinguir datos actuales de información antigua.
